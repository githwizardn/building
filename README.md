# კორპუსი

ინტერაქტიული 3D ვებ-ვიზუალიზატორი და ბინების მონაცემთა ბაზა ვარკეთილი-3-ში მდებარე კორპუსისთვის.

---

## 🚀 როგორ გავუშვათ პროექტი (Quick Start)

პროექტის ლოკალურად სანახავად საჭიროა Node.js.

1. გახსენით ტერმინალი პროექტის საქაღალდეში.
2. გაუშვით ლოკალური სერვერი:
   ```sh
   npm run serve
   ```
3. ბრაუზერში გახსენით: `http://localhost:3000/public/`

---

## 📂 პროექტის სტრუქტურა და ფაილები

პროექტი დაყოფილია რამდენიმე ძირითად ნაწილად:

*   **`/public`** — ეს არის საიტის მთავარი ნაწილი.
    *   `index.html` — შეიცავს საიტის ინტერფეისს (HTML/CSS) და 3D მოდელის მართვის ლოგიკას (JavaScript).
*   **`/output`** — აქ ინახება ყველა გენერირებული და საბოლოო ფაილი, რომელსაც საიტი იყენებს:
    *   `building.glb` — ჩვენი კორპუსის 3D მოდელი.
    *   `building_config.json` — კონფიგურაცია, რომელიც ეუბნება საიტს სად რა არის.
    *   `residents.public.json` — ბინების მონაცემები, რომელსაც ვებ-გვერდი აჩვენებს.
*   **`/scripts`** — ავტომატიზაციის სკრიპტები:
    *   `rebuild-building.py` — Python სკრიპტი Blender-ისთვის (აგენერირებს 3D მოდელს).
    *   `build-public-data.mjs` — Node.js სკრიპტი, რომელიც ამზადებს მონაცემებს საიტისთვის.
*   **`/reference`** — არქიტექტურული დოკუმენტაცია და ფასადის ანალიზი.

---

## 🛠️ ტექნოლოგიური სტეკი (Tech Stack)

პროექტი აწყობილია შემდეგი ტექნოლოგიებით:

*   **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+).
*   **3D ვიზუალიზაცია:** Three.js (მოდელის ჩატვირთვა და კამერის მართვა).
*   **3D გენერაცია:** Python (Blender-ის `bpy` API).
*   **მონაცემთა დამუშავება:** Node.js.
*   **ფორმატები:** JSON (მონაცემები) და glTF/GLB (3D მოდელი).

---

## 🏗️ 3D მოდელი

`output/building.glb` არის კორპუსის ზუსტი 3D ასლი, რომელიც აწყობილია რეალური კონტურის მიხედვით. მოდელი მოიცავს ყველა სართულს, აივნებს, სახურავს და ფანჯრებს. 

თუ გსურთ მოდელის ხელახლა აწყობა ან რედაქტირება Blender-ში, გამოიყენეთ შემდეგი ბრძანება:
```sh
blender --background --python scripts/rebuild-building.py -- --model-only
```
